3 Arquitectura Funcional del Sistema
====================================

Este capítulo describe cómo el modelo conceptual del capítulo anterior se materializa dentro de
la aplicación. Mientras que el capítulo 2 define las entidades fundamentales (Orden, Tramo,
Parada y Viaje) desde un punto de vista conceptual, este explica cómo se organizan dentro de la
estructura funcional del TMS y cómo interactúan con el resto de componentes del sistema.

El objetivo es dar una visión clara de la organización del sistema dentro de Odoo: los menús
principales, las entidades del modelo de datos operativo y los tres bloques que se apoyan en
ellas, la planificación, la tarificación y la integración con sistemas externos.
